# 설치와 사용법

## 설치

서버 버전에 맞는 jar 하나를 고릅니다. 두 jar의 게임 규칙(확률, 강화, 진화, 고유능력, 전투)은 똑같고 메뉴 화면만 다릅니다.

| jar | 서버 | Java | 메뉴 |
|---|---|---|---|
| `WeaponSystem-1.19.4-<버전>.jar` | Paper 1.19.4 | 17 이상 | 상자 GUI |
| `WeaponSystem-26.3-<버전>.jar` | Paper 26.3 | 25 이상 | 대화창 (Dialog) |

1. GitHub Actions의 **Build** 실행 결과에서 `WeaponSystem-1.19.4` 또는 `WeaponSystem-26.3` 아티팩트를 받습니다.
   직접 빌드하려면 JDK 21과 JDK 25를 설치하고 `./gradlew build`를 실행합니다. 결과는 `paper-1.19.4/build/libs/`, `paper-26.3/build/libs/`에 생깁니다.
2. 서버의 `plugins/` 폴더에 다음을 넣습니다.
   - 고른 WeaponSystem jar
   - **Vault** (필수)
   - Vault를 지원하는 경제 플러그인 (예: EssentialsX). 없으면 돈으로 하는 뽑기를 쓸 수 없고, 마일리지 뽑기만 됩니다.
3. 서버를 켭니다. 플레이어 데이터는 `plugins/WeaponSystem/players/<UUID>.yml`에 저장됩니다.

## 프로젝트 구조

| 폴더 | 내용 |
|---|---|
| `core/` | 확률, 강화, 진화, 고유능력 규칙과 데이터 모델. 버전과 상관없음. 단위 테스트 포함 |
| `shared/` | 두 버전 모두에서 그대로 컴파일되는 Bukkit 코드 (전투, 데이터 저장, 명령어, 동작 처리) |
| `paper-1.19.4/` | 1.19.4 API 이름(`Compat`)과 상자 GUI |
| `paper-26.3/` | 26.3 API 이름(`Compat`)과 대화창 UI |

## 명령어
| 명령어 | 권한 | 설명 |
|---|---|---|
| `/무기` (`/weapon`) | 모두 | 무기 메뉴 열기 |
| `/무기관리 파편 <플레이어> <D\|C\|B\|A\|S\|SP> <수량>` | `weaponsystem.admin` | 파편 지급 (음수면 회수) |
| `/무기관리 마일리지 <플레이어> <수량>` | 〃 | 마일리지 지급 |
| `/무기관리 아이템 <플레이어> <아이템> <수량>` | 〃 | 보조 아이템 지급 (예: `PROTECT`, `REROLL`) |
| `/무기관리 장비 <플레이어> <종류> [등급] [강화]` | 〃 | 시스템 장비 지급 (예: `검 S+ 5`) |
| `/무기관리 확인 <플레이어>` | 〃 | 보유량 확인 |
| `/무기관리 초기화 <플레이어>` | 〃 | 파편, 마일리지, 아이템 초기화 |

`weaponsystem.admin`은 기본적으로 OP에게 있습니다.

## 메뉴
- **전투 중 잠금**: 맞은 지 10초 안에는 `/무기`를 열 수 없습니다.
- **뽑기**: 일반, 고급, 마일리지 뽑기. 결과는 결제하는 순간 정해지고 바로 저장되므로, 결과 창을 닫아도 잃지 않습니다.
- **강화 / 진화 / 무기 고유능력**: 대상 장비를 **손에 든 채로** 메뉴를 엽니다.
- **무기 조합**: D급 장비 조합, 고유능력 아이템과 진화 아이템 조합. 장비 재료로는 이름이 없는 일반 다이아 장비만 쓰입니다.
- **인벤토리**: 파편, 마일리지, 보조 아이템 보유량.

## 구현하면서 정한 것
- 보조 아이템(상승권, 방지권, 강화권, 변경권 등)은 실제 아이템이 아니라 플레이어 데이터에 개수로 저장됩니다. 거래나 분실 걱정이 없습니다.
- 시스템 장비는 내구도가 닳지 않습니다 (부서지지 않음).
- 서버 전체 공지는 A급 이상 파편, 7강 이상 강화, S- 이상 진화만 나갑니다.
- 공격 쿨타임이 덜 찬 상태로 치면 고유능력 추가 피해도 같은 비율로 줄어듭니다 (연타 남용 방지).
- 돌진 거리는 속도로 밀어내는 방식이라 지형과 마찰에 따라 조금 달라질 수 있습니다.
